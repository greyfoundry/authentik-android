# User, Authenticator, and Android Integration Plan

## Goal

Turn the project into a useful normal-user companion and add Android-native surfaces.

## Deliverables

- application dashboard
- own account/sessions/credentials
- access requests
- widgets and deep links
- optional Wear OS read-only surfaces
- authenticator/device approval only when an upstream integration contract is secure and stable
- optional self-hosted push delivery if required

## Acceptance

Normal users can use the app without admin permissions, and authenticator features do not introduce a proprietary security protocol unsupported by authentik.
