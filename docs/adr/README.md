# Architecture Decision Records

Accepted decisions:

- 0001 - Native Android with Kotlin and Compose
- 0002 - Generated OpenAPI transport and version quirks behind stable handwritten contracts
- 0003 - AppAuth Authorization Code with PKCE
- 0004 - Generated Retrofit transport with OkHttp
- 0005 - Manual dependency injection first
- 0006 - Keystore-backed AEAD credential storage
- 0007 - Administrative writes are online-only
- 0008 - Material 3 Adaptive and Navigation 3
- 0009 - Apache License 2.0
- 0010 - No required Greyfoundry backend
- 0011 - Central risk classification for mutations
- 0012 - Feature gating by version, capability, and permission
- 0013 - Per-instance custom CA support without TLS bypass
- 0014 - Single app for admin, user, and future authenticator surfaces

New durable architecture choices require a numbered ADR rather than an unexplained code convention.
