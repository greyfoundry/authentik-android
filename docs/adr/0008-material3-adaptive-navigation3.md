# ADR 0008: Material 3 Adaptive and Navigation 3

- Status: Accepted
- Date: 2026-09-08

## Context

Current AndroidX provides the required adaptive and predictive-back primitives, so custom breakpoint/navigation frameworks are unnecessary.

## Decision

Use stable Navigation 3 and Material 3 Adaptive scene/list-detail patterns for phone, tablet, and foldable layouts.

## Consequences

Use stable releases; previews require a separate ADR.
