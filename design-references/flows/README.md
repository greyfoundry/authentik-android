# Flow Capture Policy

This directory may index or contain only project-owned authentik Companion flow sequences and explicitly redistributable material with a recorded license. Do not commit commercial gallery recordings, exports, proprietary copy, another product's trade dress, credentials, OAuth codes, server details, or user data.

Flow notes must identify the problem and state sequence, then distinguish observation from the project decision. Manual recordings are review aids, not automated regression protection.

If screenshot or recording automation is proposed, ADR 0015 must first define deterministic inputs, Linux CI parity, failure artifacts, baseline review, storage limits, and data-redaction rules. Current behavior is protected with semantic and instrumented tests.
